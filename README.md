
# 🤖 AI Graph-Based Recommendation System

This project is a **Hybrid AI Recommendation System** built using Graph Theory, Machine Learning, and AI Agent logic. It recommends items to users based on similarity, graph relationships, and intelligent decision-making.

---

## 🚀 Features

- 📊 Graph-Based Recommendation System
- 🤝 User Similarity using Cosine Similarity
- 🔥 Popularity-Based Recommendations
- 🧠 AI Agent (Rule-Based)
- 📁 CSV File Upload Support
- 📈 Graph Visualization (NetworkX)
- ⚡ Streamlit Web App

---

## 🧠 Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- NetworkX
- Dotenv
